08 — OPEN-COLLECTOR / OPTO DATA (MCU TX → pin 5)
================================================

WHAT THIS BLOCK IS
------------------
DSMR Data (RJ12 pin 5) is open-collector:
  - Meter / simulator only PULLS LOW
  - Ghost / OSM pull-up (1–10 kΩ to ~5 V) makes HIGH
Real meters use an optocoupler on this path.


5 V vs 3.3 V — ANSWER
---------------------
ESP32 UART TX stays on **3.3 V**. It does NOT drive pin 5 directly.

  • 3.3 V domain: ESP32 TX → series R → opto LED → GND
  • 5 V / P1 domain: opto transistor collector → RJ12 pin 5 (OC)
                     emitter → GND
                     optional 4.7 kΩ pin5 → P1_5V for bench without Ghost

So: “Data uses 5 V” means the **RJ12 wire** is in the 5 V OC world.
Your MCU pin never becomes a 5 V output.


EXAMPLE WIRING
--------------
  ESP32 TX (GPIO, 3.3 V UART)
       │
      R_LED (~220–470 Ω; set LED current for CTR + speed)
       │
       ▼
    opto LED ── GND

    RJ12 pin5 (P1_DATA) ── collector (open collector)
    emitter ── GND
    optional: 4.7 kΩ from pin5 to P1_5V

Idle: TX such that LED is OFF → transistor OFF → pin5 pulled high by Ghost.
Mark: TX such that LED ON → transistor ON → pin5 LOW.

Firmware: inverted UART is common on P1 — if gibberish, toggle invert.
Send only while Request (circuit 07) is active.


PARTS
-----
**Same as Request — open-collector high-speed opto:**

| Qty | Part | Brand | LCSC search |
|-----|------|-------|-------------|
| 1 (of 2 total) | **6N137SDM** (or 6N137) | **onsemi** | `6N137SDM` |
| alt dual | VO2630 / HCPL-2631 | Vishay / Broadcom | one IC for Req+Data |

6N137 VO is **open collector** → wire collector to RJ12 pin5 (and optional 4.7k to P1_5V). Perfect DSMR match.

Toshiba **TLP2361** ([C123773](https://www.lcsc.com/product-detail/C123773.html)) is faster/nicer SMD but **totem-pole** — do **not** tie VO to pin5; use TLP2361 → BSS138 → pin5 instead.

Bypass: **100 nF** on opto VCC–GND.
Do NOT use slow PC817 for Data.

MOSFET bring-up fallback (no opto):
  ESP32 TX → gate; source → GND; drain → pin5 (+ 4.7k to P1_5V)
  BSS138 / 2N7002


KICAD
-----
Nets: MCU_P1_TX, P1_DATA.
Place near RJ12. Never route ESP32 TX copper onto pin5.


TEST
----
4.7k to P1_5V on pin5, scope: idle HIGH; "U" stream → clean edges.
Ghost + Request high → valid telegram.
