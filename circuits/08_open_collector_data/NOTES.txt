08 — OPEN-COLLECTOR / OPTO DATA (MCU TX → pin 5)
================================================

WHAT THIS BLOCK IS
------------------
Per DSMR, Data (pin 5) is open-collector / open-drain:
you only PULL LOW; the OSM pull-up (1–10 kΩ) makes HIGH.
Real meters use an optocoupler on the TX path.

CHOSEN APPROACH (THIS BUILD)
----------------------------
**Optocoupler (or digital isolator) output stage** — see circuit 11.
Must work cleanly at **115200** baud → use a **fast** part.

Bring-up fallback: discrete N-MOSFET OC (BSS138) if opto not stuffed.

NECESSARY PIECES
----------------
1. Opto LED driven from ESP32 TX (series R on 3.3 V domain).
2. Opto transistor / OC on P1 side → RJ12 pin5.
3. Optional local pull-up 4.7 kΩ pin5 → P1_5V (bench without OSM).
4. ESD on pin 5 (circuit 09).
5. Firmware: send only while Request active; watch invert flag.

MOSFET FALLBACK
---------------
  ESP32 TX → Gate; Source → GND; Drain → pin5 (+ optional 4.7k to P1_5V)
  Parts: BSS138 / 2N7002

RECOMMENDED PARTS (OPTO PATH)
-----------------------------
- TLP2361, 6N137, or Si86xx + FET if needed for true OC
- Do NOT drive pin5 with push-pull 3.3 V UART directly

KICAD
-----
Nets: MCU_P1_TX → opto LED; P1_DATA → RJ12 pin5.
Place near RJ12.

TEST
----
4.7k to P1_5V on pin5, scope: idle high; "U" chars → clean edges.
Ghost receives valid telegrams when Request high.
If gibberish: toggle UART invert (double-invert is a common bug).
