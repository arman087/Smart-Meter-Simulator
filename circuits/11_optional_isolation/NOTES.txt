11 — P1 ISOLATION (OPTOS — IN SCOPE)
===================================

STATUS
------
For this build, optocouplers on Request + Data are **in scope**
(DSMR-like meter behaviour). Full floating P1 ground needs an
isolated 5V DC-DC as well.

THE CORE RULE ABOUT USB DATA
----------------------------
USB D+ / D− need a **shared ground** with the PC when using board USB.
You cannot float USB GND without a USB isolator and still flash.

So: MCU/USB domain can stay common; isolate **RJ12** if you want
protection / realism.

SIGNAL ISOLATION (REQUIRED FOR THIS BUILD)
------------------------------------------
1. Opto / digital isolator: RJ12 pin2 (Request) → ESP32 GPIO
2. Opto / digital isolator + OC: ESP32 TX → RJ12 pin5 (Data)

Parts — **115200 baud needs speed**:
  Prefer: TLP2361, 6N137, Si86xx, ADuM1201-class
  Avoid for Data: PC817 (often too slow)

TRUE GALVANIC ISOLATION (OPTIONAL EXTRA)
----------------------------------------
3. Isolated 5V DC-DC: SYS_5V or P1 path → P1_5V_ISO (≥300 mA; 1W modules
   are often only ~200 mA — check current; may need 2W / higher)
4. Separate GND vs GND_ISO pours; RJ12 pins 3/6 on GND_ISO
5. PCB slot / keep-out under barrier

If you skip (3): shared ground + optos = DSMR-like signals, **not**
full isolation.

USB ISOLATION (SEPARATE TOPIC)
------------------------------
Only if you want PC GND ≠ board GND while using USB data:
  ADuM3160 / ISOUSB211 / external USB isolator dongle.
Not required for v1.

KICAD
-----
Label domains clearly. Place optos near RJ12.
If iso DC-DC: barrier, creepage, silk GND vs GND_ISO.

TEST
----
Request 5V → MCU GPIO toggles through opto.
Data streaming → Ghost valid telegram at 115200.
If iso claimed: ohmmeter USB GND open from RJ12 GND.
