05 — ESP32-C3-MINI-1 (MCU CORE)
===============================

WHAT THIS BLOCK IS
------------------
Brain: replay telegrams from microSD on P1, Wi-Fi for config/OTA,
USB for first flash/logs, GPIO for Request, UART into Data opto.

NECESSARY PIECES
----------------
1. ESP32-C3-MINI-1 module (N4 / N4U — built-in antenna).
2. VDD decoupling per datasheet (100 nF + bulk near pins) from VCC_3V3.
3. EN pin: RC reset (e.g. 10 kΩ pull-up + 1 µF to GND).
4. Native USB: GPIO18 = D-, GPIO19 = D+ (circuit 01).
5. Antenna keep-out: no ground pour under antenna area.
6. Strap awareness (GPIO8, GPIO9, etc.).

POWER
-----
VCC_3V3 from circuit 03 (from SYS_5V / TPS61023) — never from bq25185 V+/VSYS alone.

PIN PLAN (starter)
------------------
- USB D-/D+     : IO18 / IO19
- UART TX       : → Data opto (circuit 08/11)
- Request sense : GPIO IN ← Request opto (circuit 07/11)
- SPI           : microSD (circuit 12)
- I2C optional  : OLED (circuit 10)
- LED / button  : free GPIOs (circuit 10)

RECOMMENDED PARTS
-----------------
- ESP32-C3-MINI-1-N4 (or N4U)
- Do NOT invent chip-down for v1

REFERENCES
----------
- Espressif ESP32-C3-MINI-1 datasheet + HW guidelines
- https://github.com/espressif/kicad-libraries
- P1 Ghost MCU sheet — reuse keep-out / EN RC

KICAD
-----
Import Espressif footprint. Silk: antenna end clear of metal.

TEST
----
USB enumerates → blink → Wi-Fi STA joins → SD file list → P1 replay.
