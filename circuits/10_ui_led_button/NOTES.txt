10 — UI: LED + BUTTON (± OLED)
==============================

WHAT THIS BLOCK IS
------------------
Field feedback without a laptop: Request active, sending, SD error,
which telegram / profile, battery/charger status (if sensed).

NECESSARY PIECES
----------------
1. At least one LED + series resistor from GPIO.
2. One tactile button to GND + pull-up (profile select / next file).
3. Avoid boot-strapping pins for the button.

OPTIONAL (RECOMMENDED FOR FIELD USE)
------------------------------------
4. 0.96" OLED SSD1306 I2C — show profile name, REQ, SD OK.
   Power from VCC_3V3; SDA/SCL to free GPIOs.

RECOMMENDED PARTS
-----------------
- 0603 LED + 1k–3.3k
- 6×6 mm tactile switch
- Optional: SSD1306 0.96" module or bare panel + footprint

KICAD
-----
Silk labels for LED meaning. OLED away from antenna if possible.

TEST
----
LED toggles; button logged; OLED shows selected telegram name.
