12 — microSD (TELEGRAM STORE)
=============================

WHAT THIS BLOCK IS
------------------
Primary offline library of DSMR P1 telegrams for field replay.
Not SDRAM/PSRAM — those are volatile and the wrong tool.

Field flow:
  1. At home: copy .txt telegrams onto the card (or upload via Wi-Fi UI).
  2. In building: ESP32 reads file → plays on P1 when Request is active.

PART
----
Hirose DM3AT-SF-PEJM5 (Card1). SPI only. VCC_3V3 only (never 5 V).

LOCKED SPI MAP (see FIRMWARE_GUIDE.md)
--------------------------------------
  SD_SCK  → GPIO0  → connector CLK  (pin 5)
  SD_MOSI → GPIO1  → connector CMD  (pin 3)
  SD_MISO → GPIO3  → connector DAT0 (pin 7)
  SD_CS   → GPIO6  → connector DAT3 (pin 2)

  VDD pin4 → VCC_3V3 + 10 µF + 100 nF
  VSS pin6 + shell pins → GND
  DAT1/DAT2 → NC (or 10 kΩ to 3V3)
  SW_A / SW_B → unused for v1 (no SD_CD GPIO)

Optional 33–47 Ω series on SPI lines.

FIRMWARE
--------
- FatFS, folder e.g. /telegrams/*.txt
- Detect card via SD.begin() / mount errors (no CD switch)
- MODE (GPIO9) or Wi-Fi UI selects file

KICAD
-----
Away from ESP32 antenna keep-out. Short SPI traces; GND under connector.

TEST
----
Mount card → list files over USB serial.
Select telegram → with Request active, Ghost receives valid frame.
