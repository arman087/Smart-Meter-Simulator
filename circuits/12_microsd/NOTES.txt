12 — microSD (TELEGRAM STORE)
=============================

WHAT THIS BLOCK IS
------------------
Primary offline library of DSMR P1 telegrams for field replay.
Not SDRAM/PSRAM — those are volatile and the wrong tool.

Field flow:
  1. At home: copy .txt telegrams onto the card (or upload via Wi-Fi UI).
  2. In building: ESP32 reads file → plays on P1 when Request is high.

NECESSARY PIECES
----------------
1. microSD push-push or push-pull PCB holder.
2. SPI wiring to ESP32-C3 (simplest) OR SDMMC 1-bit/4-bit.
3. 3.3 V power from VCC_3V3 (circuit 03) — card must NOT see 5 V.
4. Optional card-detect switch → GPIO.
5. Decoupling 100 nF (+ 10 µF) next to card VDD.

SPI PIN PLAN (starter — adjust to free GPIOs)
---------------------------------------------
  CS, MOSI, MISO, SCK → free GPIOs (avoid USB 18/19 and straps).
  Document final map in schematic silk / firmware.

FIRMWARE
--------
- FAT filesystem (FatFS)
- Folder e.g. /telegrams/*.txt
- Button or Wi-Fi UI selects which file to replay
- CRC16 check optional before send

RECOMMENDED PARTS
-----------------
- microSD connector (JLCPCB / DigiKey common push-push)
- 8–32 GB microSD (FAT32)
- Optional: 33–47 Ω series on SPI lines for EMI

KICAD
-----
Place holder away from ESP32 antenna keep-out.
Short SPI traces; GND under connector.

TEST
----
Mount card → list files over USB serial.
Select telegram → with Request high, Ghost receives valid frame.
Hot-plug optional; cold boot with card inserted is enough for v1.
